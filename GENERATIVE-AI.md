# Generative AI & Resonite
This document describes the current AI policies in place at Yellow Dog Man Studios (YDMS), for the platform Resonite. AI is a very wide and thorny subject, which is why this document is kept simple, and to the point.

## Quick overview

Yellow Dog Man Studios strongly values human work and building the platform for the long term, rather than taking shortcuts. At the same time we understand the technology is complex and multi-faceted and not everyone in the community shares the same ideals as we do. 

To reflect this, we separate our policies by who they apply to.

Here is a quick overview:

- Official Yellow Dog Man Studios use (code, assets, features & user data)
    - These are rules for ourselves, so they are most strict
- [Open source component contributors](LLM-USAGE.md)
    - This affects community contribuing code to our open source coomponents
    - Those components are shipped by us to everyone as part of Resonite install
    - These are still pretty strict, with looser rules on private use
- [User content on Resonite](USER_CONTENT_AI_POLICY.md)
    - Use up to discretion of each user
    - While we have our own opinions and rules on the technology, we also value freedom of each user to make their own determination for their own work
    - We only require disclosure through tagging to allow effective filtering for other users
    - Training on content from other users is prohibited without their explicit consent

## Policy on generative AI
The policy regarding generative AI is as follows:

- Generative AI is not in widespread use at Yellow Dog Man Studios.
    - Any proprietary Resonite code contributions must follow the public contributor policy as a baseline, with additional restrictions below:
        - Contributing code generated by an LLM (beyond trivial auto-completion) is prohibited
        - Using proprietary code as an input for LLM-based helpers is prohibited.
        - Team members may use LLM-based helpers at their own discretion with the goal of understanding better a concept, error or something they are unfamiliar with, while remembering to research the information further, and to not be completely reliant on it. Researching concepts from multiple sources is strongly encouraged.
    - Creating or modifying any official assets, such as textures, audio, video, 3D models, worlds or objects using generative AI is prohibited
- Code contributions to our public repositories by staff or 3rd party community contributors must follow [public contributor policy](LLM-USAGE.md)
- Generative AI features **will not** be implemented in Resonite in any official capacity with narrow exceptions (see #Exceptions section below)
- User data will **never** be used to train models in an official capacity or sold to 3rd parties to train on
- Individual users and business customers **may** use and implement generative AI if they wish to do so, though such uses **will not** be officially endorsed.
    - Any content published on Resonite platform must follow the [User AI disclosure policy](USER_CONTENT_AI_POLICY.md)
    - Personal use by team members is also allowed under this as long as it's published on their personal accounts and could not be confused for official use
- Users wishing to train AI models using Resonite must obtain direct and explicit consent from each user in the potential training data.
    - Training models using Resonite-specific data such as metrics, API responses and such is prohibited.

We encourage users to report violations of this policy via our [moderation portal](https://moderation.resonite.com).

# Transparency relating to AI applications
Resonite is a very complex platform which depends on many software libraries. Some of them use **fully local** machine learning models to provide some essential features:

## Machine Learning
- RNNoise
     - **Use:** Noise removal from a user’s speech.
     - Licensing: Code under BSD Clause 3; training data provided by OpenSLR under Creative Commons ShareAlike 4.0.
     - **Rationale:** Significantly improves quality of user voice. Industry standard & open source
- OVRLipSync
     - **Use:** Solely on Windows, used to derive blendshape data from a user’s speech.
     - Licensing: Code under proprietary license; training data of an unknown origin.
     - **Rationale:** Industry standard for social VR applications with voice, with no full replacements
- OpenLipSync
    - **Use:** Primarily on Linux, used to derive blendshape data from a user’s speech.
    - Licensing: Code under Apache 2.0; training data provided by OpenSLR under Creative Common ShareAlike 4.0.
    - **Rationale:** Open-source alternative to OVRLipSync that is cross platform. Fidelity does not match OVRLipSync.
- Opus
    - **Use:** Audio codec used for transmit user’s speech & audio streaming. Although machine learning features are disabled at the moment, they usually help dealing with packet loss and low-bitrate audio.
    - Licensing: Code under the Opus license.
    - **Rationale:** Industry standard open source codec

This list will be updated when new dependencies including machine learning are added to Resonite.

Internal machine learning uses also include code suggestions (through intellicode, or similar system) or creative application helpers (for instance, smart selection or background removal on images). 

We encourage users to notify us of any other libraries currently in use that are not in this list. To do so, please create an issue.

## Exceptions
We make narrow exceptions for allowing generative AI (or adjacent) technologies official integrated into Resonite. In general exceptions are made when:
- It serves a significant public good purpose, such as improving core accessibility
- Has zero or very low risk of harm by our use
- Is not replacing a task handled by a human
- It is not replacing a creative or decision making task
- Solution can be self-hosted and is ideally optional install by the user

### Whisper AI
- **Use:**
    - Speech to text conversion for realtime captions for accessibility
        - Allows deaf & hard of hearing users to communicate
        - Combined with live translations, allowing a level of communication across language barrier
    - Transcribing voice messages to text
    - Voice commands
- **Rationale:**
    - Open publicly available model
    - Generally sufficiently accurate for transcribing speech in different languages and varying accents (depending on exact variant of the model)
    - While we find aspects of how and why this model was trained problematic, ethically providing acessibility features to hearing impaired users is a higher priority
    - Optional self hosted solution
    - Our use does not replace any human roles
- **Restrictions:**
    - We **DO NOT** ship any of the models with default Resonite installation
    - Any accessibility features with this model **MUST** be publicly available for self hosting to avoid paygating them
        - Resonite hosted instances can be monetized due to cloud compute costs, but would only be provided as convenience, never replacement for self-hosting

### Translation LLM models
- **Use:**
    - Translating feedback and messages we receive in languages we do not understand
    - Optional in-game live-translation feature (combined with speech to text technology)
- **Rationale:**
    - Traditional translation models perform poorly with certain language pairs with significant differences in structure, such as English <---> Japanese
    - Major translation engines (such as Google Translate) and API's will use LLM technology internally, making it near impossible to avoid
    - Restricting use to non-LLM technology would complicate communication with parts of the community and disadvantage certain languages over others
    - Ethically, we consider disadvataging users based on their native language to be a worse alternative
    - Currently LLM technology seems to be the only choice we're aware of for effective self-hosted machine translations for those language pairs
    - Models can be self hosted by users locally
    - We are not replacing any human translation roles with this technology (e.g. for translating UI)
- **Restrictions:**
    - We **DO NOT** ship any translation models to the end user as part of the default Resonite installation
    - We **DO NOT** use translation models in cases where user-facing offline translation can be used for high quality translations:
        - Resonite UI locale must be human translated
        - Official annoucements must be human translated if presented in other languages
    - We will prefer viable models with ethically sourced training data over similar models with unknown or less ethical sources

# Future changes
We reserve the right to re-evaluate any aspects of this policy in the future and make changes when necessary.

Whether the changes make the rules more or less strict, they need to be discussed internally first and approved before making any public changes.

Any major changes to the rules (beyond fixing typos or improving wording) will be announced through our official channels to inform the community.
